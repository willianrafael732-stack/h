Como usar na mesa

Regra opcional: some o poder dos dois elementos em d10. Custo sugerido: metade da quantidade de dados, arredondada para cima, com mínimo de 1 Mana. A mistura não soma novamente Inteligência, arma ou outros bônus. No mesmo elemento, use dois aportes de poder distintos; não conte os mesmos pontos duas vezes.

Os efeitos novos são propostas para o mestre: não impõem dano, cura, duração ou sucesso automático. “Sombrio” aparece como Sombra. Raio e Elétrico permanecem separados, como no cadastro original.

As rolagens desta página são locais. Para registrar resultados para o grupo, use os mesmos dados na Mesa de RPG →
